# Bugfix Skill

## 使用场景

- 修复线上 bug。
- 修复失败测试。
- 修复用户反馈的问题。
- 修复回归问题。

## 工作流程

1. 复现问题或定位触发路径。
2. 找到根因。
3. 分析影响范围。
4. 做最小修复。
5. 补回归测试。
6. 运行验证。
7. 总结根因和修复方式。

## 禁止

- 顺手重构。
- 只修表象。
- 没有有效验证就结束。

## 验证命令

```bash
make test
make check
```
