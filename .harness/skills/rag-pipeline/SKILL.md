# RAG Pipeline Skill

## 使用场景

- 新增文档摄取。
- 修改切分或 embedding 策略。
- 更新检索过滤或排序。
- 修改答案合成 prompt。
- 排查检索缺失或低质量检索。

## 工作流程

1. 读取相关架构和领域文档。
2. 识别摄取、索引、检索和合成边界。
3. 为变更行为补聚焦测试。
4. 记录足够元数据以诊断检索失败。
5. 运行验证。

## 约束

- 不要把检索逻辑和展示代码混在一起。
- 产品要求来源归因时，不要静默丢弃来源。
- 不要在向量元数据中存储密钥或原始凭据。
